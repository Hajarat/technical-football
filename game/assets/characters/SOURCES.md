# Character models

`player.glb` (outfield, short sleeves) and `keeper.glb` (long sleeves, gloves) are generated by `tools/characters/build_characters.py`
with MPFB2 (MakeHuman for Blender). The glTF files are committed; nothing downloaded is.

- Rig: MPFB's **Mixamo-compatible rig** (`mixamo`, bones named `mixamorig:*`, imported by Godot as `mixamorig_*`), so Mixamo animations can be layered later.
- Body: adult male, macro sliders gender 1.0, age 0.5, muscle 0.62, weight 0.42; the height slider is bisected until the skin is 1.80 m.
- Materials: one flat material per role (`skin`, `hair`, `shirt`, `shorts`, `socks`, `boots`, `gloves`, `eyes`). The game tints them from `FigureKit`; only the eyes keep a texture.
- Sizes (this build): player.glb 1.15 MB, keeper.glb 1.22 MB.

## One-time install (macOS, Blender 5.2)

```sh
# 1. the add-on, into Blender's user extensions (not the repo)
curl -L -o /tmp/mpfb.zip "https://extensions.blender.org/download/sha256:c075b3e9b94b8e5556a5f03f4653602d02ea306de08126e8f55ed6dee28a2dad/add-on-mpfb-v2.0.18.zip"
/Applications/Blender.app/Contents/MacOS/Blender -b --command extension install-file -r user_default -e /tmp/mpfb.zip

# 2. the asset packs, unzipped into MPFB's user data folder
D="$HOME/Library/Application Support/Blender/5.2/extensions/.user/user_default/mpfb/data"
B=https://files.makehumancommunity.org/asset_packs
for p in makehuman_system_assets/makehuman_system_assets_cc0 shirts01/shirts01_cc0 pants01/pants01_cc0 \
         underwear04/underwear04_cc0 shoes01/shoes01_cc0 gloves01/gloves01_cc0; do
  curl -L -o /tmp/pack.zip "$B/$p.zip" && unzip -qo /tmp/pack.zip -d "$D"
done
```

## Rebuild

From the repository root:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python tools/characters/build_characters.py
# optional flat preview renders: -- --preview /tmp/preview     (output folder: -- --out <dir>)
godot-mono --headless --path game --import     # once, so Godot imports the new .glb
```

Godot extracts the eye textures next to the models (`*_brown_eye.jpg`); they are import artefacts of the `.glb`.
